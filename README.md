# ✏️ 찾아zoom

> **찍으면 써주는 캠퍼스 분실물 서비스** — 주운 사람은 사진만 찍고, 잃어버린 사람은 AI와 대화만 하면 됩니다.

**🔗 배포 주소: <https://jusweossda.vercel.app>** (휴대폰 브라우저에서 바로 열어 보세요)

해커톤 주제 **"AI로 만드는 우리 주변의 문제 해결"** 출품작입니다. 한양여자대학교 캠퍼스 분실물을 예시로 만들었습니다.
화면에 "시제품 · 가짜 데이터"라고 표시된 것처럼 시연용으로 만든 시제품입니다.

---

## 📌 해결하려는 문제

| 지금의 분실물 게시판 | 찾아zoom |
|---|---|
| 습득자가 글을 직접 써야 해서 귀찮고, 시간·장소·물건 정보가 빠진 글이 많아요. | 사이트에서 **사진만 찍으면** AI가 물건·장소·시간을 읽어 글을 대신 써 줘요. |
| 잃어버린 사람이 게시판을 처음부터 끝까지 넘겨 가며 찾아야 해요. | **AI와 대화하면** 등록된 글 중 후보(최대 3개)를 "이것인가요?" 하고 보여줘요. |
| 아무나 "내 거예요" 하고 가져갈 수 있어요. | 글쓴이가 정한 **확인 질문**을 맞혀야 쪽지가 연결돼요. |
| 누가 돌려받았는지 알 수 없어서 오래된 글이 계속 남아요. | 글 상태(**보관 중 → 연락 중 → 반환 완료**)가 자동으로 바뀌고, 반환된 글은 검색에서 빠져요. |

## 🔄 사용 흐름

### 습득자(글쓴이)
1. 로그인 후 **주웠어요** → 사이트 안 카메라로 물건을 촬영 (갤러리 업로드 없음)
2. 촬영 시각과 GPS 좌표로 주소·건물명을 확인 — "📍 여기가 맞나요?" (틀리면 주소 검색·지도 핀 이동)
3. 층수·호수·메모 입력
4. AI가 사진을 분석해 **종류·색·브랜드·특징과 게시글 초안**을 작성 (예: "한양여자대학교 도서관 1층에서 오후 2시 40분에 흰색 에어팟 프로를 주웠습니다.")
5. 본문 수정, 익명 여부, 현재 보관 위치 선택, **확인 질문과 정답** 입력(선택) → 등록 (상태: `보관 중`)
6. 주인이 쪽지를 보내오면 대화하고, 돌려준 뒤 **[반환 완료]** 처리

### 분실물 주인
1. 메인의 **잃어버렸어요**에서 **로그인 없이** AI와 대화 ("어제 오후에 도서관에서 흰색 에어팟 잃어버렸어요")
2. AI가 종류·색·장소·시간을 뽑고, 부족하면 되물어요
3. 후보 카드(사진은 흐리게)가 나오면 **[이거예요]** 또는 **[아니에요]**
   - 아니에요 → 그 글을 빼고 추가 질문 후 다시 검색, **2번 실패하면 직접 검색 화면으로 안내**
   - 이거예요 → 로그인 → **확인 질문에 답하기** → 통과하면 글쓴이와 **쪽지** 연결 (상태: `연락 중`)

## ✨ 주요 기능

- **📸 사이트 내 촬영** — `getUserMedia`로 바로 촬영(휴대폰은 후면 카메라). 긴 변 1280px JPEG로 줄여 올리고, 카메라를 못 쓰면 파일 촬영으로 대체해요.
- **📍 위치 확인** — GPS 좌표를 카카오 로컬 API로 주소·건물명으로 바꾸고 오차(m)도 저장해요. 틀리면 주소·장소 검색과 **카카오 지도 핀 이동**으로 고쳐요. 위치 권한을 거부하면 바로 주소 검색으로 안내해요.
- **🤖 AI 글 작성** — 비전 LLM이 사진을 분석해 JSON(종류·색·브랜드·크기·특징)과 게시글 초안을 만들어요. 작성자는 모두 수정할 수 있고 AI가 실패해도 직접 쓸 수 있어요.
- **💬 AI 대화 후보 추천** — 대화에서 조건을 뽑고("어제 오후" → 날짜 범위), `보관 중` 글 중에서 날짜·종류 필터 후 AI가 다시 비교해 **최대 3개**만 보여줘요. 종류·색이 다르면 제외하고 점수가 낮은 후보는 내지 않아요.
- **🔒 확인 질문** — 글쓴이가 질문과 정답을 정하면, 정답은 비밀 표에만 저장돼 **브라우저로 내려가지 않아요.** 서버가 비교하고(글자가 같거나 AI가 같은 뜻이라고 판단하면 통과), 3번 틀리면 10분간 잠겨요. 정답이 공개 글에 그대로 적혀 있으면 등록할 때 막아요.
- **💌 쪽지** — 글쓴이와 주인 두 사람만 읽을 수 있는 1:1 대화방. Supabase Realtime으로 새 쪽지가 바로 나타나요.
- **🏷️ 상태 관리** — `보관 중` → `연락 중`(확인 질문 통과 + 쪽지 연결) → `반환 완료`(글쓴이가 처리). 반환 완료 글은 AI 후보·기본 목록에서 빠지고 "반환 완료" 필터에서만 보여요. 글쓴이는 [다시 보관 중으로]로 되돌릴 수도 있어요.
- **🔎 직접 검색** — 목록에서 검색어(물건·색·브랜드·장소·특징), 종류, 상태로 찾을 수 있어요.

## 🛡️ 개인정보·보안 설계

- **RLS(행 보안 정책)를 모든 표에서 켰어요.** 쪽지·대화방은 참여한 두 사람만, 글 수정은 글쓴이만 할 수 있어요.
- **확인 질문의 정답(`item_secrets`)은 읽기 정책이 없어요.** 서버(service_role 키)만 읽고, 대화방 생성도 서버 전용 DB 함수로만 열려요. 확인 질문이 있는 글은 브라우저에서 직접 연결할 수 없어요.
- **로그인 아이디(username)는 공개하지 않아요.** 닉네임만 공개되고, 익명 글은 "익명"으로 보여요.
- **AI·카카오 REST·서버 키는 모두 서버(API Route)에서만** 호출해요. 브라우저로 나가는 키는 공개용(Supabase anon 키, 카카오 JS 키)뿐이에요.
- 후보 카드의 사진은 흐리게 처리하고, 사진 속 글자에 적힌 지시문이나 사용자 입력의 지시문은 AI가 따르지 않도록 막았어요.

## 🧰 기술 스택

| 영역 | 사용한 것 |
|---|---|
| 프레임워크 | Next.js 16 (App Router) + React 19 + TypeScript |
| 스타일 | Tailwind CSS 4 + 직접 만든 레트로 윈도우 스타일 CSS (모바일 우선) |
| 백엔드·DB | Supabase — Auth(아이디+비밀번호), Postgres + pgvector, Storage(사진), Realtime(쪽지), RLS |
| AI | OpenAI `gpt-5.4-mini` (사진 분석·글 작성·대화·재정렬·채점, JSON 스키마 출력) · 임베딩 `text-embedding-3-small`(벡터 검색 준비 완료) |
| 위치 | 카카오 로컬 API(주소 변환·검색) + 카카오 지도 JavaScript SDK(핀 이동) |
| 배포 | Vercel (GitHub `main`에 push하면 자동 배포) |

서버 API Route: `app/api/geo`(주소 변환·검색) · `app/api/ai/analyze`(사진→글 초안) · `app/api/lost/chat`(주인 대화·검색) · `app/api/items/embed`(검색용 벡터) · `app/api/items/[id]/verify`(확인 질문 채점)

## 🚀 로컬에서 실행하기

### 0. 준비물
- Node.js **20.9 이상**, Git
- Supabase 프로젝트 1개, 카카오 개발자 앱 1개, OpenAI API 키 1개

### 1. 내려받기와 설치
```powershell
git clone https://github.com/s3y2ung-beep/sshh.git
cd sshh
npm install
```

### 2. 환경변수 채우기 — `.env.local.example` 안내
```powershell
Copy-Item .env.local.example .env.local
```
`.env.local`을 열어 값을 채우세요. 어떤 키를 어디서 얻는지는 `.env.local.example`의 주석에 적혀 있어요. (`.env.local`은 `.gitignore`에 들어 있어 GitHub에 올라가지 않아요.)

| 이름 | 어디서 | 공개 여부 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase → Project Settings → API | 공개 가능 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 같은 곳의 anon / Publishable 키 | 공개 가능 (RLS로 보호) |
| `SUPABASE_SERVICE_ROLE_KEY` | 같은 곳의 service_role / Secret 키 | **서버 전용** |
| `KAKAO_REST_API_KEY` | 카카오 개발자 → 앱 키 → REST API 키 | **서버 전용** |
| `NEXT_PUBLIC_KAKAO_JS_KEY` | 카카오 개발자 → 앱 키 → JavaScript 키 (플랫폼 → Web에 도메인 등록) | 공개 가능 (도메인 제한) |
| `OPENAI_API_KEY` | OpenAI 대시보드 → API keys | **서버 전용** |
| `OPENAI_MODEL` | (선택) 기본값 `gpt-5.4-mini` | — |

> 🔑 **키 값은 절대 GitHub, 채팅, 스크린샷에 올리지 마세요.** Windows PowerShell 5.1에서 값을 `|`로 다른 명령에 넘기면 눈에 안 보이는 문자(BOM)가 붙어 키가 망가질 수 있어요.

### 3. 데이터베이스 만들기
Supabase 대시보드 → **SQL Editor**에서 `supabase/migrations/` 폴더의 파일을 **이름 순서대로** 한 개씩 붙여 넣어 실행하세요.

1. `…083458_create_items_and_storage.sql` — 글 표·비밀 정답 표·사진 저장소
2. `…100203_create_profiles.sql` — 회원 프로필(가입 시 자동 생성)
3. `…120000_hide_username.sql` — 로그인 아이디 비공개
4. `…150000_add_embedding_search.sql` — pgvector 검색 열·함수
5. `…180000_create_messaging.sql` — 쪽지(대화방·메시지) + 실시간
6. `…210000_verify_question.sql` — 확인 질문 + 반환 완료 글 쪽지 차단

그리고 Authentication → Providers → Email에서 **"Confirm email"(이메일 확인)을 꺼 주세요.** 이 서비스는 아이디를 내부 이메일 형식으로 바꿔 가입하기 때문에 메일 확인이 켜져 있으면 가입 직후 로그인되지 않아요.

### 4. 실행
```powershell
npm run dev
```
<http://localhost:3000> 을 열어 **회원가입**(아이디 + 비밀번호) 후 사용하세요.

- 카메라·위치는 **HTTPS(또는 localhost)** 에서만 동작해요. 휴대폰으로 테스트하려면 배포 주소를 쓰거나 `cloudflared` 같은 터널을 쓰세요.
- 카카오 지도는 카카오 앱의 **[플랫폼 → Web]에 등록한 도메인**에서만 보여요. `http://localhost:3000`도 등록하세요. 지도가 안 떠도 주소 검색으로 진행할 수 있어요.
- 빌드 확인: `npm run build` · 프로덕션 실행: `npm run start`

## ⚠️ 알려진 한계

- 벡터 검색(pgvector)은 준비돼 있지만, 사용 중인 OpenAI 프로젝트에 임베딩 모델 권한이 없어 **현재는 AI가 최신 글 30개를 직접 비교**하는 방식으로 동작해요. 권한이 열리면 새 글부터 자동으로 벡터가 만들어져요.
- 로그인 없는 AI 대화의 횟수 제한(IP당 10분에 20번)과 확인 질문 잠금은 **서버 메모리 방식**이라 시연용이에요.
- 글 삭제·수정 기능은 아직 없어요.
- 시제품이라 비밀번호를 잊으면 찾을 수 없어요.
